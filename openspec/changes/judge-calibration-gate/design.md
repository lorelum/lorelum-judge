# Design

## Decisions

1. Keep current `GatePolicy/v1`, `CalibrationArtifact/v1`, and `evaluateEnforcement` semantics stable. Add `GatePolicy/v2` and `CalibrationArtifact/v2`; new dataset, report, and decision records start at v1. New gate enforcement requires a verified v2 calibration.
2. One calibration case belongs to a task group and has a split, task class, evidence shape, criterion, expected decisive verdict, case category, label provenance, evidence references, and exactly the instrument's declared number of observations. A task group may contain behavior variants; all variants and repetitions stay in the same split and count as one independent group.
3. Default to three observations per case and a `2/3` agreement threshold. The unique decisive verdict with the highest count is used only when it reaches the threshold; ties, insufficient agreement, and `unknown`/`insufficient` without a qualifying decisive plurality become indeterminate. Provider failures are recorded separately and never converted to quality failures.
4. Default policy requires 20 independent holdout groups for each required case category in every declared criterion/task-class/evidence-shape scope. Categories are decisive, behaviorally equivalent, and anti-example or partial. Expected verdicts remain kind-valid: equivalent contract behavior maps to `met`; `equivalent` is a verdict only for comparison criteria.
5. Mandatory contract criteria accept only `met`. Quality and comparison criteria declare acceptable decisive verdicts. Among mandatory findings, any supported unacceptable verdict makes the overall result fail; otherwise any indeterminate finding makes it indeterminate; only all-supported acceptable findings pass. Missing/unsupported evidence never creates a quality failure. Optional criteria remain advisory.
6. Use per-task-group metrics. False accept is any unacceptable gold case accepted in a group divided by groups containing unacceptable gold cases; false reject is any acceptable gold case rejected divided by groups containing acceptable gold cases. Abstention and disagreement count a group at most once over all groups in the scope. Report numerators, denominators, estimates, and Wilson 95% intervals. Holdout qualification requires category coverage, nonzero rate denominators, minimum group counts, and every applicable upper bound within the frozen policy thresholds. Defaults: false accept 5%, false reject 10%, abstention 20%, disagreement 20%. Development groups never qualify.
7. Bind definition, instrument, policy, dataset, report, and declared scope identities. A loader recomputes the report and returns an in-process verified value; raw status or report fields alone never establish qualification. The v2 artifact has explicit status and validity interval. New calibration starts in shadow; expiry, revocation, changed identities, or out-of-scope use degrade to the policy fallback.
8. Gate result separates quality outcome from execution mode. It contains a deterministic localized summary (Chinese default, English supported), criterion-level user-readable findings, cited evidence, and next steps. Localization does not affect measurement or calibration identity; no model writes the summary.

## Package Ownership

`protocol` owns schemas, cross-record validation, and canonical identities. `judge` owns Wilson interval calculations, calibration report generation, verified loading, gate aggregation, and result formatting. Tests use synthetic deterministic data; no provider or benchmark package is added. Label provenance is retained, but the caller remains responsible for label truth.
