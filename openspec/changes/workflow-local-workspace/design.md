# 设计

## 归属和边界

新增 `apps/local-workspace` 作为 Bun 本机服务和浏览器页面的 composition root；protocol 拥有版本化跨边界事件，workflow 拥有计划、授权、动作和检查，runtime-bubblewrap 拥有隔离，judge 保持现有公开语义。应用不成为核心 package 的依赖。复用 #64/#67，不建立另一套计划或授权语义。

页面使用 `lorelum/lumen-ui` 的 React 组件、LumenProvider 和 Linen 主题，而非另建基础控件；接入应固定可复现版本并遵循组件库的 React、Tailwind 和样式入口要求。该仓库当前为私有，组件标记 UNLICENSED，文档只描述本地打包；必须先明确可供本仓库消费者和 CI 使用的分发方式，不能假设公共 registry 可用或直接复制私有源码。

以对话为首页，用户消息和真实模型回复构成多轮消息流；用户在页面配置模型并选择工作区后，计划、权限确认、执行和结果均在对话中呈现。对话调用复用宿主配置的 ModelPort，按每次完整消息、模型配置及接收方预览并单次授权；它不会自动读取本地项目，确定性离线替身不冒充通用对话模型。聊天和工作流授权互不替代。

## 工作区和模型

路径输入不限制为预设目录。发现前说明本地名称发现范围并收集排除设置；排除在正文读取前生效。支持诊断覆盖 Git HEAD、冲突 index、隐藏修改标志、链接、特殊文件和 mount，以及 Linux openat2、bubblewrap 和工具链前提。展示 canonical root、原现场、纳入排除和真实独立副本身份；不把上传文件冒充 live root。原工作区不写入。仅支持具备真实隔离前提的 Linux，不降级执行；命令读取整个副本，命令写入仅限批准的子目录；不提供网络、原项目 Git 元数据或用户 home。

宿主创建配置不可变、对象身份稳定的 ModelPort，向现有 provider 注入固定 generation config；用户可在本机页面输入端点、名称和可选密钥，配置变化重建实例并撤销相关授权。密钥仅保存在宿主进程内存，提交后清除输入，不进入状态快照、事件、日志或持久记录；连接测试前单独展示接收方和完整测试内容并取得同意。离线模式明确标识，不可静默替代真实模型。规划首次和调整请求在发送前展示接收方及完整数据，包含 task、资料、旧计划及本次意见；权限覆盖完整请求且不能静默扩大。实施和评审的数据披露分别授权；错误不得泄漏密钥。

## 会话与权限

宿主维护内存会话和实际用户决定；页面仅提交明确决定，不能传入函数或恢复序列化能力。确认绑定计划完整 identity 与 revision，生成新版本立即使旧确认和执行授权失效，失败不恢复。一次审核可分别记录确认、文件读写、具体 argv/cwd、模型披露、实际可实施的限制和期限。计划确认不授予执行权；越界、失效、撤销、过期或前提变化时停止。修改 workspace、模型接收方或配置、命令、权限或检查配置撤销受影响的授权。unsupported 硬费用、内存、网络和文件 IO 限额明确拒绝；计费风险说明不是费用保证。刷新显示真实内存状态和无事件回放限制；重启后无会话或授权恢复。

执行及公开 judge 评审期间，每次调用真实模型前宿主暂停并在受保护的状态中呈现实际消息、配置和接收方；该次请求获明确批准后才发送。通知事件只含元数据，拒绝、期限、取消或前提失效会释放等待并阻止外发。独立的文件、命令及类别权限仍须先批准。

## 事件和安全

workflow 在真实提出、授权、开始、结果、检查、评审和终止检查点输出类型化通知；宿主分配会话身份和严格递增序号并按白名单投影，不直接公开内部 observations、正文或命令输出。已完成动作和检查在撤销或失败时保留；未知不可伪造。无通用事件平台、持久历史或断线续传。客户端仅使用安全文本渲染。

服务绑定 loopback；校验 Host 和 Origin，状态变更要求同源令牌及受限 JSON 请求，拒绝跨站冒充和宽泛 CORS。报告及事件接口同样限制访问。无账户、多用户或远程访问承诺。sandbox 是共享内核边界，不是 VM。

## 输出和验证

stdout/stderr 返回字符串的 UTF-8 字节数之和不得超过共享预算；多字节截断与无效序列必须按实际编码计量，保留截断、取消、超时和进程树清理语义。报告区分失败、未知、未执行、截断及实际通过；展示 diff、独立检查和公开 judge。

严格校验 OpenSpec 和统一验证，真实 Linux 沙箱与浏览器验收用户自行选择的 dirty/untracked 项目，检查原项目内容、模式、未跟踪内容和 Git 状态不变；覆盖拒绝、版本失效、权限不足、过期、前提变化、撤销和失败。真实模型只在用户明确授权具体接收方和披露内容后调用；未授权时记录端到端未实测。Benchmark 公开 starter 为可选附加验收。
