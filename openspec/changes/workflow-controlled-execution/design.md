# 设计

## 范围及前置

#65 是计划、授权、隔离执行、独立证据、公开 judge 和报告的单次闭环；复用 #64 的 PlanningSession，含 d9a9541 的失效修复。#64 未合并，本 change 的草稿 PR 暂以该分支为基底，前置合并后转向 main；不覆盖 #64 的实现或把本 change 混入其 PR。

## 信任和权限

计划确认与操作、资料披露、资源上限分别显示和记录。宿主受信任地输入实际用户决定；模型输出和序列化记录不自行授予权限。审核绑定完整计划 identity/revision、来源、起点、具体路径、argv/cwd、披露对象、隔离配置和上限身份；每个副作用前及异步结果提交前复核当前状态，撤销、过期或变更立即取消。自然语言 scope 不是文件或命令权限。补读不静默修改确认标准。

## 现场与 Linux 隔离

展示选中的已提交、未提交和未跟踪文件、排除原因及敏感材料策略，确认后复制字节、模式、删除事实形成独立起点；不运行 hooks/filters，不信任链接或特殊文件，不支持的现场明确拒绝。保留原始工作区和系统变更的区别。

首批 Linux 非特权 bubblewrap，控制进程在 Linux 内运行；Windows 原生不宣称支持。强制 user、mount、PID、network、IPC、UTS 隔离、禁止后代新 user namespace、无 capabilities、独立 session、父进程死亡清理、最小环境与 FD。仅将工具链只读和批准的工作副本子树映射进 sandbox；不暴露宿主项目、凭据、socket、Git 元数据或宿主网络。禁止不受支持的细粒度写权限及网络能力时必须拒绝，不静默扩大范围。共享内核和只读工具链属于信任基础。必须真实验证文件/网络/子进程/namespace 绕过及超时清理；隔离能力无法满足时执行前拒绝。

## 受控修改、证据和评审

现有 text ModelPort 不支持 tools；implementer 可通过结构化动作提议与宿主受控工具循环工作，输出不能直接批准、写入或证明检查通过。所有读写和命令严格校验当前授权及预算；写入须绑定预期旧内容身份，命令只接受已批准的 argv/cwd 而非模型生成任意 shell。不得修改原项目。

冻结候选内容身份并停止 implementer，从该状态创建独立 runner 副本；实际执行审核过的检查，记录版本、命令、环境、输出、截断和完成状态。控制面保存 evidence，候选不能伪造。消费 judge 公开 review/gate，不重定义测量；分别保留质量、检查完整性和 enforcement eligibility。报告实际 diff、计划/标准与代码身份、证据、评审、失败/未知、用量和停止原因。不自动提交、推送、写回或交付。

## 可实施资源上限

按审核值实施总时间、单命令时间、模型调用与动作/命令次数、读取/输入/写入字节、输出量；对不支持的费用、内存或其他硬上限明确拒绝，不声称实现。执行前准入计数，超时或撤销终止整个 sandbox 进程树。失败、取消、未知与未执行不能变成通过。

## 验证

仅用确定性模型替身；真实临时 Git 项目包括 dirty/untracked，实际修改、独立检查、公开 judge 和报告。覆盖版本失效、冲突、权限不足、预算、越权及实际隔离攻击。Linux 环境记录版本；本机 WSL2 仅验证过 bwrap 启动，尚不构成越权隔离证明。执行 frozen install、strict OpenSpec、validate；改 runtime 追加 conformance。#66 的恢复、长期修复、授权交付与经验整理不属于本 change。
