# 设计

## 边界

本 change 实现 #52，不执行文件修改、命令、评审或交付。总体连接与验收归属见 `docs/architecture/engineering-workflow.md`。用户审核计划与独立操作授权必须分开；模型输出、引用资料和确认标记均不是认证或操作授权。

## 记录与身份

protocol 提供版本化资料、计划与决定记录及校验。资料包含来源 ID、来源类型、版本、定位、内容和可用状态。计划包含 TaskContract、目标、范围、步骤、检查、非目标、缺失和冲突；每条验收来源必须映射到资料。计划身份覆盖整个计划，使用现有 canonical identity。修改内容必须新版本，不能继承旧确认。

workflow 使用 ModelPort 生成提案，传入无工具请求；对模型结果进行结构及交叉引用校验。用户要求调整时重新生成新版本；用户决定只能经宿主调用的显式决定入口输入，不从模型输出推断。确认绑定计划身份及版本；撤销、失效、调整后不可进入实施。确认资格仅表示计划已确认，不表示操作获准。

补读资料不得静默修改已确认标准。资料缺失与必须用户决定的冲突分别保留；冲突未解决不得确认。生成失败或无效输出如实返回错误。实现不承诺持久化、跨进程恢复、认证或隔离。

## 验证

通过确定性模型替身及公开入口验证提出、调整、新版本确认、撤销、失效和冲突。运行 OpenSpec strict validation、仓库 validate 和公开消费者 smoke，不依赖真实模型或密钥。
