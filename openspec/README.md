# OpenSpec

This directory records contract-class changes before implementation.

Each active change lives under `changes/<change-name>/` and contains:

- `.openspec.yaml`
- `proposal.md`
- `design.md`
- `tasks.md`
- `specs/<capability>/spec.md`

The change is the review boundary. Keep one declared problem per change, link its
issue, record the commands used for verification, and update task checkboxes as
work completes.
