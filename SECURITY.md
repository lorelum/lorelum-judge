# Security

## Reporting

Do not open a public issue for a vulnerability that could expose credentials,
repository contents, execution environments, or model prompts.

Report the issue privately to the maintainers with:

- affected package and version;
- reproduction steps or a minimal proof of concept;
- expected impact;
- whether untrusted task, repository, log, or model content can trigger it.

## Scope

Security-sensitive areas include prompt injection boundaries, tool approval,
path authorization, command execution, credential isolation, evidence
redaction, cache identity, and deserialization of persisted contracts.
